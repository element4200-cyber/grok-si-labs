# Grok SI Labs

The Super Intelligent Laboratory: a redesigned creative studio inspired by the Engineers workflow, with original styling and copy. The app is a Cloudflare Worker with a bundled frontend.

[Open the public laboratory](https://grok-bots-studio.element4200.chatgpt.site)

## Features

- Responsive bot gallery with six working starters, category filters, search, bookmarks and recorded activity ranking.
- D1 cloud project storage with per-user ownership, share-to-gallery controls, shared project links and local backups.
- Free starter builder is the default and requires no API key. It creates working apps from six editable starter templates.
- Optional AI app builder uses three real Grok API requests: planning, code generation and review. It requires an xAI key and API credits; no free unauthenticated Grok API is claimed.
- Three Grok chat personas with independent visit-scoped conversations.
- Sandboxed app previews, phone preview, source inspection, HTML export and portable JSON project import/export.
- Phantom and Solflare wallet connection, live SOL balance and pump.fun token creation using the official `@pump-fun/pump-sdk` 4.1.0 `createV2Instruction`.
- Metadata upload through `https://pump.fun/api/ipfs`, with existing HTTPS metadata URI support when that endpoint is unavailable.
- Simulation, transaction review, wallet signature, submission, confirmation tracking, Solscan and pump.fun links. SOL pair, optional dev buy in the same atomic transaction with an exact SOL maximum and 1% slippage, optional visible priority fee, no studio service fee. Phantom signs and sends through its own connection. Pending signatures are saved immediately and can be checked from My creations. Holder rewards are optional and permanent.
- Optional paired Windows desktop bridge for detecting and opening `C:\Program Files\Grok Bot\Grok Bot.exe`. It does not control the desktop app's chat or use undocumented private APIs.

## Start locally

Use Node 22+ and pnpm. Run `pnpm install`, `node scripts/build.mjs`, then `node scripts/serve.mjs`. Open `http://localhost:4387`.

Run `node --test tests/*.test.mjs` for transaction and server checks. Tests use mock RPC calls and never broadcast to Solana.

## AI setup

Use Settings in the site to enter an xAI key for the current page visit, or configure `GROK_API_KEY` as a hosted runtime secret. Keys are never written to browser storage. The server forwards the key only to `https://api.x.ai/v1/responses`. Default model: `grok-4.7`, configurable with `GROK_MODEL`. API usage is billed by xAI.

## Solana setup

Configure hosted secret `SOLANA_RPC_URL` with a production mainnet RPC provider for reliable usage. The default is the public Solana mainnet endpoint, which can rate limit. Wallet extensions require a supported browser; embedded previews may not expose them. No private wallet keys or seed phrases are requested or stored. Each launch requires a wallet signature.

Actual token creation, paid AI requests, and desktop app opening are not exercised by automated verification. No token was launched during development.

## Desktop pairing

Run `node desktop-bridge.mjs` on Windows. Paste its generated pairing code into Desktop companion on the website. The bridge is bound to loopback port 4318, accepts only the exact hosted site and localhost development origins, and requires a random bearer token. Restarting the bridge invalidates the old code. Stop with Ctrl+C. Browsers may require permission for local network access. There is no general filesystem, shell, chat history, or wallet access.

## Data and sharing

Creations are stored in D1 and backed up in browser storage. Hosted identity uses the platform's authenticated user header; users can edit only their own projects. Sharing a project makes it visible in the gallery to visitors allowed by the site's audience. The hosted site is public: anyone can browse the site and published projects without signing in. Saving or editing cloud projects requires optional ChatGPT sign-in. Unpublished drafts are visible only to their owners. The leaderboard combines recorded cloud project opens and local starter opens. Bookmarks and token confirmation records are browser-local. Chat and API keys stay in memory for the visit. Project previews run with scripts allowed but without same-origin access or network access. Exported HTML is user-owned source; review it before hosting.

The local preview uses Node's SQLite adapter and the generated migration files, with one mock local user. It does not simulate hosted audience permissions. Production uses the real D1 binding and dispatch-owned identity. SQL migrations are generated by Drizzle Kit and packaged at `.openai/drizzle`.

The site is independent and is not affiliated with xAI, Engineers, or pump.fun. All studio bots share a smooth spherical shape and two diagonal capsule eyes.
